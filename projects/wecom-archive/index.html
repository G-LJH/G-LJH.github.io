企业微信会话存档

用第三方回调替代官方存档，把合规成本从约 9 万/人/年降到接近 0，并推动成为公司服务能力。

GitHub 全部作品

会话存档是合规与质检的核心能力，但官方接口成本高、对接复杂，也难与内部 CRM / AI 知识库打通。本方案通过第三方回调完成消息捕获与结构化存储，打通从捕获到入库的链路。

背景与痛点

  • 官方接口服务费高，中小团队难负担
  • 直接对接底层 SDK / 解密流程复杂
  • 聊天数据难灵活接入内部系统与 RAG

工程亮点

  • 部署轻量：现代包管理与容器化，便于上线
  • 可运维：日志监控 + health 自检
  • 可扩展：预留 RAG / 质检接口，存档数据可进入后续智能应用

部署运行

  • 示例环境：2 核 4G · Ubuntu 22.04 · 1Panel · OpenResty · MySQL 8.0

技术栈

  • Python · Flask · MySQL · Webhook · 企业微信
