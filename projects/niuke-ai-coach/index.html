牛客 AI 面试教练

求职准备要对齐面经、简历与 JD，却极度重复——换一个岗就从头再来。做成一条长流程 Agent：自动抓取面经、解析简历与 JD，生成 8 大模块个性化准备报告。

Agent 应用 长流程任务 报告生成 开源可跑
查看 GitHub 全部作品

背景与问题

面经在网站、简历是 PDF、JD 经常是截图——准备一次岗位要手工搬运多次。企业侧已经在用 AI 筛人；个人侧若仍靠复制粘贴，效率差距会被拉大。这个项目要解决的是可重复的准备流水线，不是再写一篇「面试经验博客」。

输入足够杂 岗位名、JD 文本/截图、简历 PDF、面经抓取数量。
输出足够结构化 8 大模块报告，可按模块查看并导出 Markdown。

三个关键判断

01 · 流程

杂输入进同一条流水线

爬虫、PDF 解析、OCR 都为同一目标服务：给大模型足够干净的「人 × 岗」上下文。

02 · 结构

按面试官视角分模块

不是一篇散文总结，而是整体评价、岗位分析、高频考点、项目深挖、行为面等可执行清单。

03 · 可靠

长任务必须可恢复

断点续传保存进度，避免网络抖动导致「跑一半作废」——这是 Agent 应用能否真用的分水岭。

我怎么做

  • 面经抓取：按岗位搜索并提取问题；限速与重试，降低失败率。
  • 材料解析：简历 PDF 结构化；JD 支持文本与截图 OCR。
  • 报告生成：基于百炼模型输出 8 模块准备报告，并支持模块化阅读。
  • 产品外壳：Flask Web 展示进度与结果，支持 Markdown 导出。

结果：8 大模块报告

  • 整体评价 · 岗位分析 · 高频考点分类解析 · 高频考点清单
  • 项目深挖 · 行为面试准备 · 临场应对策略 · 推荐复习资料
  • 端到端 Web 流程可演示；任务进度可恢复，报告可导出
