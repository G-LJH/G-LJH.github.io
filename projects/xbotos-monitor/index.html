xbotos 机器人监控

轻量级在线状态监控：实时面板、连续失败防误报、阿里云短信告警与历史追踪。

GitHub 全部作品

针对 xbotos 平台机器人服务提供实时健康监测。机器人连续异常时通过阿里云短信告警，帮助运维尽快发现问题。

总览面板

  • 定时检测在线状态，自动刷新
  • 支持一键启停监控服务

告警策略

  • 连续失败阈值：连续 N 次失败才发短信，降低单次抖动误报
  • 告警冷却：避免短信轰炸
  • 阿里云 SMS：稳定推送告警

机器人管理

检测历史

我做了什么

  • 模块化架构：配置 / 数据 / 监控 / 告警分层
  • 告警策略：连续失败 + 冷却，降低误报
  • 容器化：Docker Compose，可部署到 1Panel

技术栈

  • Python · Streamlit · Pandas · Requests
  • 阿里云短信 SDK · Docker / Docker Compose · 本地 JSON 持久化
